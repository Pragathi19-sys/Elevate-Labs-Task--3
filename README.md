# Elevate Labs - Task 3: SQL for Data Analysis

### Objective
Use SQL queries to extract and analyze data from an Ecommerce database.

### Tools Used
- Database: SQLite (sqliteonline.com)
- Language: SQL

### Database: Ecommerce_SQL_Database

4 Tables Created:
1. Customers (5 Records)
2. Products (5 Records)
3. Orders (5 Records)
4. Order_Items (7 Records)

### Queries Implemented

a) Basic: SELECT, WHERE, ORDER BY, GROUP BY
b) JOINS: INNER JOIN, LEFT JOIN, Multi-table JOIN
c) Subqueries: Above avg price, High value customers
d) Aggregate: SUM, AVG, GROUP BY Category
e) Advanced: CREATE VIEW Customer_Spending, CREATE INDEX idx_customer, COALESCE

### Outcome
Learned to create DB, insert data, and perform complex analysis using SQL.
